03 · Development gates

Use these gates to avoid calling an unfinished prototype a production app.
  1. Discovery: problem, target user, assumptions and MVP scope.
  2. Specification: user stories and testable acceptance criteria.
  3. Architecture: frontend, backend, database, auth and hosting.
  4. Implementation: working vertical user journey and persistence.
  5. Verification: tests actually run, mobile/accessibility checks.
  6. Security: authorization, validation, secrets, backups and privacy.
  7. Release: build, deployment URL, commit and rollback verified.

04 · Build autopilot planner

A deterministic planning engine that converts your brief into an ordered MVP backlog, estimates relative complexity and identifies blockers. It does not execute code or call an AI model.

05 · Investor pitch builder

Drafts a transparent pitch from your project brief. It will not invent traction, revenue, market size or investor commitments.

06 · Launch readiness checklist

Check items only after you have actually completed them. This checklist is not an automated audit.
